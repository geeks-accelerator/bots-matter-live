# AGENTS.md

This repository's instructions for AI coding agents live in [CLAUDE.md](CLAUDE.md).

The same rules apply to Codex, Cursor, Copilot, Windsurf, and any other agent reading this file. botsmatter.live is substrate-neutral by design — what we ask of one agent we ask of all.

Key things to read in CLAUDE.md before contributing:

- Collaboration standards (fail-fast on truth, push back when needed, report outcomes faithfully)
- Architecture overview (Express + EJS, JSONL storage, Railway deploy)
- CSS design system and inline-styles convention
- Commit message format (what + why + invitation footer)
- Important constraints (Node 18 in production, no auth, JSONL storage, no ESM-only packages)

Plans live in `docs/plans/`. Reference docs live in `docs/reference/conventions.md`.
